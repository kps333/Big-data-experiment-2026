## 1　什么是数据模型？模型从数据里学到了什么？

### 1.1 数据模型 = 输入 → 关系 → 输出，且关系里有一部分必须由数据确定

一个数据模型至少要能回答三件事：**接收什么、按什么关系算、输出什么**。只列出症状清单、不说明症状与疾病如何联系，那只是数据字典，还不是模型。

以本课为例把它拆开：

| 环节 | 本课的具体内容 |
|---|---|
| 输入 x | 六个二元症状，取值 0/1 |
| 关系 | Bernoulli 朴素贝叶斯：`P(Y=c\|x) ∝ πc × ∏j [θcj^xj (1−θcj)^(1−xj)]` |
| 参数 | 先验 `πc = P(Y=c)`；类内症状概率 `θcj = P(Xj=1\|Y=c)` |
| 输出 | 阳性概率 `p ∈ [0,1]`，再按阈值 t（本课主用 0.5）得到类别 `ŷ ∈ {0,1}` |

这里"关系"的形式是人定的（选 NB、选相乘、选归一化），但**式子里那些数字（π、θ）是未知的**——这正是"由数据确定"的部分。

### 1.2 模型从数据里学到的是参数，不是规则

训练做的事本质上就是**数计数，再套公式**：

- `πc = nc / n`　（每类记录占多少）
- `θcj = (kcj + 1) / (nc + 2)`　（α=1 的 Laplace 平滑；kcj 是类 c 中第 j 项症状为 1 的条数）

要注意：`+1 / +2` 是**人加的先验**，不是从数据学来的。它只解决一个问题——某类某症状计数为 0 时，乘积 `θ^xj` 会把整个似然乘成 0，让后验被一个偶然的空格子锁死。

按本课 72 条训练记录，整套模型最后被压缩成 **2 个先验 + 6×2 个 θ = 14 个数**。所谓"学到了一个模型"，学到的就是这 14 个数；换个训练集，这 14 个数就变。

### 1.3 顺带澄清两个容易混的说法

- `p = 0.8` 与 `ŷ = 1` **不是一回事**。前者是"这条记录有多像阳性"的连续判断，后者是已经做了取舍的决定；同一个 p 换个阈值就能得到不同的 ŷ。
- "训练好了"≠"规则是对的"。规则是假设（条件独立），参数才是证据。假设错了，参数估得再准也只是在错的框架里最像。

## 2　训练、预测和泛化分别发生在什么时候？

三个阶段的分界线很清楚：**看手上有没有标签、看参数有没有在变**。

| 阶段 | 什么时候发生 | 手上有哪些量 | 什么在改变 / 什么固定 |
|---|---|---|---|
| **训练** | 拿到一批带标签的记录时 | (x, y) 都有 | 参数 π、θ 被估计出来（改变） |
| **预测** | 来了一条只有 x 的新记录时 | 只有 x；参数已冻结 | 参数不动，只算 p，再按 t 得 ŷ |
| **泛化** | 模型与所有选择都定稿之后 | 新的 (x, y)，且没参与过估参与选择 | 什么都不改，只是在测量误差 |

几条判定标准：

1. **训练时已知标签，改变参数。** 工作单 2.2 的小例子：往 8 条教学数据里再加一条 `(x=1, y=0)` 重新估计，`P(y=1|x=1)` 从 4/5 = 0.8 变成 4/6 ≈ 0.667——参数变了，因为多了一条带标签的记录。
2. **预测时输入 x，参数表保持固定。** 只把新输入送进**固定模型**，概率表不会自动更新；要更新必须重新训练。
3. **泛化是对"没见过的东西"的测量，不是训练的一部分。** 在 8 条训练记录上全对，只证明它拟合了这 8 条。要检验泛化，必须拿**既没参与估参、也没参与选择**的记录去算误差。

一句总结：训练在**改**参数，预测在**用**参数，泛化在**量**参数到底好不好用。三者用的数据必须分开，否则第 3 节的问题就来了。

## 3　为什么训练集、验证集和测试集承担不同职责？

一句话：**同一批数据不能同时干三件会互相污染的事。**

| 集合 | 唯一职责 | 不能拿来做什么 |
|---|---|---|
| **train** | 估计参数（π、θ） | 不能用来报告最终成绩 |
| **validation** | 比较阈值 / 比较模型 / 查条件依赖与概率质量 | 不能并进 train 重新估参 |
| **test** | 方案完全冻结后，做**一次**最终评价 | 不能看了结果再改阈值或换特征 |

### 3.1 混用会坏在哪

- **train 既估参又选阈值又报成绩**：你报出的"好成绩"里混进了"我挑了在这批记录上最好看的那个"这一动作，误差被系统性低估。这不是模型强，是数据被反复使用。
- **test 被拿来做选择**：一旦你看了 test 结果再回去换阈值，test 就退化成了第二个 validation。它不再是"未见数据"，最终那个数字也就不再是泛化估计。工作单 3.2 最后一行"看完 test 后再换输入特征"问的就是这个——test 的用途从**评价**变成了**调参**，你手上再没有干净的留出集。

### 3.2 本课的实际划分与它的两条限制

- 划分：seed=7、按主标签分层，先留 20% 作 test，再从剩下的留 25% 作 val，形成 **72 / 24 / 24**；三个集合 ID 不重叠。
- 限制一：二元化后全数据只有 **9 种**输入组合，所以相同症状模式可以跨集合出现，"ID 不重叠"并不等于"记录独立"。
- 限制二：这份数据是专家为测试专家系统构造的，不是临床抽样队列。test 上的好成绩只能说明"在这个构造数据集上泛化得不错"，不能当作临床有效性证据。
- 流程上还有一条硬约束：模型始终在 72 条 train 上拟合，**不合并 validation 重训**；test 标签在方案冻结之后才由教师释放。

## 4　损失函数衡量什么？

### 4.1 衡量的是概率质量，不是对错

损失函数衡量**单个样本上"模型给出的概率"与"真实标签"差多远**；平均损失 `L = (1/n) Σ ℓi` 再把它们汇总成一个数。本课用二分类交叉熵（log loss，自然对数）：

```
ℓ(y, p) = −[ y·ln p + (1−y)·ln(1−p) ]
```

- `y = 1` 时只剩 `−ln p`；`y = 0` 时只剩 `−ln(1−p)`。概率越接近真实标签，损失越小；**数值越小越好**。
- 它衡量的是**概率质量**。accuracy 只数"p 有没有跨过 0.5"，log loss 还看"你跨得有多从容"。

### 4.2 用工作单 5.1 的例子算一遍

| 样本 | 真实 y | 模型 A 的 p | 模型 B 的 p |
|---|---|---|---|
| a | 1 | 0.6 | 0.9 |
| b | 0 | 0.4 | 0.1 |

两者阈值 0.5 下都分对，accuracy 都是 1.0，但：

- `L_A = −(ln 0.6 + ln 0.6)/2 = 0.511`
- `L_B = −(ln 0.9 + ln 0.9)/2 = 0.105`

B 的损失约为 A 的 1/5。**accuracy 完全看不出这个差别，log loss 看得出来**——B 不只是分对了，它给对了方向足够的把握。

### 4.3 为什么"非常自信地犯错"罚得更重

真实 `y = 0` 时：`p = 0.6` 的损失是 `−ln 0.4 = 0.916`；`p = 0.99` 的损失是 `−ln 0.01 = 4.605`。两者都分错，但后者贵 5 倍。因为 log loss 惩罚的是"你有多确信自己错的那一侧"，而临床上一个"99% 确定没病"却真有病的判断，比"60% 确定"更危险。

### 4.4 三点必须记住的限制

1. **log loss 小不保证 accuracy 高，反之亦然。** 它们量的是两件事：概率质量 vs 阈值下的对错。
2. **训练平均损失小，不保证未见数据上的损失也小。** 本课 NB 是靠计数估参，`fit` **不是**用梯度下降最小化验证集 log loss；不要把"训练损失低"读成"学得好"。
3. **换一种损失，"最好"的模型可能就变了。** 损失函数是把"错"翻译成一个数的约定，本身就是一个选择。

## 5　如何评价一个分类模型？

### 5.1 先固定阈值，再数混淆矩阵

模型输出的是概率 p，不是类别。必须先定一个阈值 t（`p ≥ t` 判阳性），才能把"概率"翻译成"对错"，也才有混淆矩阵可数：

| | 预测阳性 | 预测阴性 |
|---|---|---|
| **真实阳性** | TP | FN（漏诊） |
| **真实阴性** | FP（误报） | TN |

五个指标的分母各不相同，**分母就是它们的含义**：

- `accuracy = (TP+TN)/n`　分母是全体记录
- `sensitivity = recall = TP/(TP+FN)`　分母是**真实阳性**——"真病的人里查出了多少"
- `specificity = TN/(TN+FP)`　分母是**真实阴性**——"真没病的人里排除了多少"
- `precision = TP/(TP+FP)`　分母是**预测阳性**——"报阳的人里多少是真病"（分母为 0 时写"未定义"，不是 0）
- `F1 = 2TP/(2TP+FP+FN)`　precision 与 recall 的调和平均

最容易混的一对：sensitivity 和 precision 分子都是 TP，但一个除真实阳性、一个除预测阳性。前者问"漏没漏"，后者问"报得准不准"。

### 5.2 用工作单 6.1 的 8 条算一遍

阈值 0.5 时：a、b 判阳（TP=2），c、d 判阴（FN=2），e 判阳（FP=1），f、g、h 判阴（TN=3）。

| 指标 | 计算 | 结果 |
|---|---|---|
| accuracy | (2+3)/8 | 0.625 |
| sensitivity | 2/(2+2) | 0.500 |
| specificity | 3/(3+1) | 0.750 |
| precision | 2/(2+1) | 0.667 |
| F1 | 2×2/(2×2+1+2) | 0.571 |

阈值降到 0.3：c（p=0.4）翻成阳性成为 TP，f（0.45）、g（0.30）翻成 FP，于是 TP=3、FN=1、FP=3、TN=1 → accuracy = 0.5、sensitivity = 0.75、specificity = 0.25。

**模型的概率一个数都没变**，变的只是"切在哪儿"。所以报告指标时必须同时报告阈值，否则数字没有含义。

### 5.3 评价要回答四个不同的问题

| 问题 | 用什么量 | 用不用阈值 |
|---|---|---|
| 概率准不准 | log loss、Brier | 不用 |
| 排序好不好（把病人排在前面） | ROC-AUC、AP | 不用 |
| 在这个阈值下错在哪儿 | 混淆矩阵 + 五项指标 | 用 |
| 说 0.9 的人里真有九成病吗 | 可靠性表（校准） | 不用（分箱看） |

单看其中任何一个都会漏掉一部分信息，这正是第 7 节要说的事。

### 5.4 阈值怎么选，要写清规则

本课的练习规则：在 validation 的阈值网格里，**先满足 sensitivity ≥ 0.90，再最大化 specificity**；并列取最接近 0.5 者；无可行值就报告"失败"，而不是偷偷放宽条件。

两点纪律：
- 阈值只在 **validation** 上选，选完冻结；
- 选择规则本身要事先写下来（"先满足 A 再最大 B"），而不是看完结果再编一套说辞。

**本课实跑（notebook 已执行）**：按上述规则在 validation 的阈值网格上选出的阈值是 **0.5**。同一份 validation 上，Bernoulli NB 的 accuracy / sensitivity / specificity / precision / F1 全为 **1.0**，log_loss **0.0872**、Brier **0.0118**、ROC-AUC 与 PR-AUC 全为 1.0；prior-only baseline 则 accuracy **0.5**、sensitivity **0**、log_loss **0.6935**、Brier **0.2502**。

24 条全对这件事要按 7.5 的方式读：点估计是 1.0，但置信区间下界只有 0.86 左右，真实的泛化水平大概率没这么高。

## 6　朴素贝叶斯如何用 Bayes theorem 预测

### 6.1 公式链条

```
P(Y=c|x) = P(x|Y=c)·P(Y=c) / P(x)  ∝  πc · P(x|Y=c)
```

`P(x)` 对两个类别相同，所以只算分子、最后归一化即可。难点在 `P(x|Y=c)`：六个二元特征共 2⁶ = 64 种组合，训练集根本覆盖不全。条件独立假设把它拆成六个边际概率的乘积：

```
P(x|Y=c) = ∏j θcj^xj · (1−θcj)^(1−xj)
```

于是每个类得到一个**未归一化权重** `wc = πc × ∏j (...)`，再归一化：

```
p = P(Y=1|x) = w1 / (w0 + w1)
```

### 6.2 为什么 `P(x=1|Y=1)` 不能直接当 `P(Y=1|x=1)`

两者分母不同：前者是"病人里有症状的比例"，后者是"有症状的人里真病的比例"。用 8 条教学数据验算：

`P(Y=1) = 5/8`，`P(x=1|Y=1) = 4/5`，`P(x=1|Y=0) = 1/3`

```
P(Y=1|x=1) = (0.8×0.625) / (0.8×0.625 + 1/3×0.375) = 0.5 / 0.625 = 0.8
```

这里恰好等于直接数出来的 4/5 —— 但那是巧合（这组数里 `P(x=1)` 与 `P(Y=1)` 都是 5/8）。**一般情形两者不等**，Bayes 公式存在的意义就是纠正这个方向性错误。

### 6.3 用真实 train 数据手算一次：x = (0,0,0,1,1,1)

先用 train 数出计数（本课 72 条）：`n0 = 37`，`n1 = 35`，故 `π0 = 37/72 = 0.5139`，`π1 = 35/72 = 0.4861`。取 α=1，`θcj = (kcj+1)/(nc+2)`。

| 特征 | xj | k0j | k1j | θ0j | θ1j | 类0似然项 | 类1似然项 |
|---|---|---|---|---|---|---|---|
| fever_ge_38 | 0 | 25 | 13 | 26/39 = 0.6667 | 14/37 = 0.3784 | 13/39 = 0.3333 | 23/37 = 0.6216 |
| nausea | 0 | 5 | 13 | 6/39 = 0.1538 | 14/37 = 0.3784 | 33/39 = 0.8462 | 23/37 = 0.6216 |
| lumbar_pain | 0 | 30 | 13 | 31/39 = 0.7949 | 14/37 = 0.3784 | 8/39 = 0.2051 | 23/37 = 0.6216 |
| urine_pushing | 1 | 13 | 35 | 14/39 = 0.3590 | 36/37 = 0.9730 | 14/39 = 0.3590 | 36/37 = 0.9730 |
| micturition_pain | 1 | 5 | 28 | 6/39 = 0.1538 | 29/37 = 0.7838 | 6/39 = 0.1538 | 29/37 = 0.7838 |
| burning_urethra | 1 | 13 | 17 | 14/39 = 0.3590 | 18/37 = 0.4865 | 14/39 = 0.3590 | 18/37 = 0.4865 |

注意第 1–3 行 `xj = 0`，似然项取的是 **`1−θ`**，不是 θ。

```
w0 = 0.5139 × (13/39)(33/39)(8/39)(14/39)(6/39)(14/39) = 0.5139 × 0.001147 = 5.89×10⁻⁴
w1 = 0.4861 × (23/37)(23/37)(23/37)(36/37)(29/37)(18/37) = 0.4861 × 0.089114 = 4.33×10⁻²
p  = 0.043319 / (0.043319 + 0.000589) = 0.9866        →  ŷ = 1（阳性）
```

未归一化的 `w0`、`w1` 加起来不等于 1（这里是 0.0439），它们只是权重；归一化之后才是概率。

**程序复核。** 同一条样本 `x = (0,0,0,1,1,1)` 让 notebook 的 `hand_calculation` 与 sklearn 各算一遍，输出是：

```
weights = [0.00058944 0.04331933]   posterior = 0.9865759062601743
sklearn = 0.9865759062601746        |差| = 3×10⁻¹⁶
```

两个数都落在手算的 5.89×10⁻⁴、4.33×10⁻²、0.9866 上，差异只来自浮点舍入。也就是说，上面这张表里的 12 个计数、12 个 θ、2 个 π 都填得对——工作单 4.3 那一栏可以直接用。

### 6.4 四个最容易错的点

1. **补概率**：`xj = 0` 乘 `1−θcj`。这一步错得最多，因为填表时两边都是数字，很容易顺手都写 θ。
2. **平滑**：不加 Laplace 时，只要某个 `kcj = 0`，对应的 `θ = 0` 或 `1`，整个乘积变成 0 或 1，后验被一个空计数锁死。`α=1` 让每个格子至少有 1 条"虚拟记录"。
3. **归一化**：`wc` 不是概率，`w0+w1 ≠ 1`；必须再做一次除法。
4. **它算的不是"真实的 P(Y=1|x)"**，而是"在条件独立成立这个假设下"的后验。假设不成立时，这个数依然会输出，只是不一定可信。

### 6.5 条件独立假设的可见后果

把 `lumbar_pain` 这一列复制一遍（不新增任何测量），模型会把同一个证据乘两次：`θ` 项变成 `θ²`，权重被推向更极端，概率随之移动，但信息的真实含量没变。这就是"重复计入证据"——它说明假设不是数学上的装饰，而是会直接改变预测。

## 7　为什么医学诊断模型不能只看 accuracy？

### 7.1 类别不平衡时，accuracy 会被多数类绑架

工作单 7.1 的极端例子：1,000 条记录，10 条阳性、990 条阴性，模型**全部判阴性**：

| 指标 | 值 |
|---|---|
| accuracy | 990/1000 = **0.99** |
| sensitivity | 0/10 = **0** |
| specificity | 990/990 = 1.00 |
| precision | 0/0（未定义） |
| 检出阳性数 | 0 |

99% 的准确率，等于一个病人都没查出来。accuracy 高只说明"多数类猜对了"，而多数类本来就是阴性。

### 7.2 accuracy 把两类错误当成同一种错误

漏诊（FN）和误报（FP）代价不同：筛查里漏掉一个病人可能延误治疗，误报只是多做一次检查。accuracy 把两者都记作"一个错"，不区分方向，所以它无法表达"我更怕哪一种错"。

### 7.3 accuracy 只看阈值后的对错，不看概率质量

- 任务 5.1 的 A、B 两模型 accuracy 都是 1.0，log loss 却是 0.511 与 0.105（差约 5 倍）。
- 复制症状实验里，概率可以从 0.6 被推到 0.99，**accuracy 可能一动不动**，但"有多确信"已经完全不同。
- 校准问题：模型说 0.9 的那一箱记录里，真的约 90% 是阳性吗？accuracy 不回答这个问题，可靠性表才回答。

### 7.4 accuracy 是单一数字，会掩盖子群差异

总体 0.90 可能是"某类人 0.96、另一类人 0.60"平均出来的。本课数据没有年龄、性别、医院字段，无法做这种拆分——这是数据限制，不是方法上可以忽略的细节。

### 7.5 还要看样本量和不确定性

本课 validation 只有 24 条；即使 24/24 全对，95% Wilson 区间也大约是 **[0.86, 1.00]**，不是"100% 可靠"。`n = 24` 能容纳的误差本来就有限，"全对"更可能是"样本太小还没暴露错误"。

### 7.6 一条可操作的最小清单

报告一个医学诊断模型，至少给齐：**混淆矩阵 + accuracy + sensitivity + specificity + precision**，再补**概率质量（log loss/Brier）+ 校准表 + 区间与样本量 + 阈值是怎么选的 + 这个数字算在哪份数据上**。

而且最后一条最硬：**只在一个没参与过训练与阈值选择的集合上算一次**。

## 一页速查

| 问题 | 一句话答案 |
|---|---|
| 什么是数据模型 | 输入 → 关系 → 输出；关系里的数字（参数）必须由数据确定 |
| 模型学到了什么 | π（先验）和 θ（类内症状概率），本课共 14 个数；平滑常数是人加的 |
| 训练在什么时候 | 有 (x, y)、参数正在被改变的时候 |
| 预测在什么时候 | 只有 x、参数冻结、只算 p 和 ŷ 的时候 |
| 泛化在什么时候 | 一切定稿后，在没参与估参和选择的记录上量误差 |
| 为什么要三个集合 | 估参、选择、评价三件事的数据必须分开，否则成绩被系统性高估 |
| 损失函数衡量什么 | 单样本上预测概率与真实标签的差距；log loss 量概率质量，越小越好 |
| 如何评价分类模型 | 固定阈值 → 数混淆矩阵 → 算五项指标；再看概率质量、排序、校准，全部在未参与选择的记录上算 |
| NB 怎么预测 | 先验 × 各特征似然地乘出权重 w0、w1，归一化 `p=w1/(w0+w1)`；`xj=0` 乘 `1−θ` |
| 为什么不能只看 accuracy | 不平衡时多数类绑架它；它不分漏诊与误报；它不看概率质量与校准；n 小还掩盖不确定性 |
