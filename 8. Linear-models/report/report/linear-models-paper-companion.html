1.2 生成过程：把「假设」变成旋钮

论文的动作在方法论上只有一句：把 LDA 的假设拆成两个可以独立拧的旋钮。等协方差高斯包含两个可分离的条件——类条件分布是高斯的，且两类共享 Σ。前者对应 γ，后者对应 λ。

x | y=k ~ N(μk, Σk)，　μ0=0，　μ1=SEP·e1

Σ0 = Id，　Σ1 = diag(1+3λ, …, 1+3λ, 1, …, 1)　（前 ⌈d/2⌉ 维被放大）

X ← sign(X) · |X|γ　（逐坐标施加，γ=1 时为恒等）

两处取舍值得注意。第一，λ 只放大正类的一半维度，而不是全部：若全部放大，Σ1 与 Σ0 只差一个标量，判别方向 Σ⁻¹Δ 反而不变，违背会被「尺度」吸收掉。第二，γ 用符号保持的幂变换而不是加偏态参数：这样它仍是双射（保序），从而不改变贝叶斯上界（§2.2、论文附录 C.3），把「分布形状」与「可分性」彻底分开。这是让 γ 成为「纯违背轴」的技术前提。

为什么必须双条件？因为单看显著性会把「稳定但极小」的差异判成胜负（γ=1.3 那点 Δ=−0.0007、p=0.017 就是这样），单看幅度又会把「大幅但不稳」的噪声判成胜负。0.005 这个阈值是预注册的，不是事后挑的——这一点比阈值取多少更重要。

2　线性判别分析：从类条件密度到一条直线

2.1 三条假设，一条也不能少

LDA 不是「假设边界是线性的」，而是从三个关于数据生成的假设出发，把线性边界推导出来。这个区别很重要：前一种说法让人误以为 LDA 比 Logistic 多假设了「线性」，其实两者对边界形状的假设完全相同（§4.1），LDA 多假设的是数据怎么生成。

(A1)　x | y=k ~ N(μk, Σk)　——类条件密度是多元正态

(A2)　Σ0 = Σ1 = Σ　——两类共享协方差

(A3)　πk 已知或可用样本比例估计

A1、A2 合起来就是「等协方差高斯」。A3 只影响截距，不影响方向（§2.3）。

2.2 后验 log-odds 的逐步代数

目标是算出 log[p(y=1|x)/p(y=0|x)]，看它是不是 x 的线性函数。由贝叶斯公式：

log[p(1|x)/p(0|x)] = log(π1/π0) + log p(x|1) − log p(x|0)

多元正态的对数密度（两类共享同一个 Σ，故行列式项与常数项相消）：

log p(x|k) = −½ (x−μk)ᵀΣ⁻¹(x−μk) + C

所以关键是算两个二次型之差。先把每个二次型展开：

(x−μk)ᵀΣ⁻¹(x−μk) = xᵀΣ⁻¹x − 2xᵀΣ⁻¹μk + μkᵀΣ⁻¹μk

相减，xᵀΣ⁻¹x 这一项在两侧完全相同，直接抵消——这是整条推导的枢纽：

(x−μ1)ᵀΣ⁻¹(x−μ1) − (x−μ0)ᵀΣ⁻¹(x−μ0) = −2xᵀΣ⁻¹(μ1−μ0) + (μ1ᵀΣ⁻¹μ1 − μ0ᵀΣ⁻¹μ0)

代回，并利用恒等式 ½(aᵀMa − bᵀMb) = ½(a+b)ᵀM(a−b)（M 对称）：

log[p(1|x)/p(0|x)] = β0 + xᵀβ，　β = Σ⁻¹(μ1−μ0)

β0 = log(π1/π0) − ½(μ1+μ0)ᵀΣ⁻¹(μ1−μ0)

这就是论文定义 2.2 的来历，也是代码里 experiment/lda_log_lab.py:305 那一行的来历：

beta0 = −0.5·(c1 − c0) + log(π1/π0)，　ck = μkᵀΣ⁻¹μk

这一步的结论：后验概率是 σ(β0+xᵀβ) 的形式，其中 σ 是 sigmoid。而这正是 Logistic 回归的模型形式。LDA 与 Logistic 的全部关系，都从这一行展开（§4.1）。

2.3 决策边界与先验的角色

决策规则是「后验大于 0.5 就判正类」，边界是 β0+xᵀβ = 0：

xᵀΣ⁻¹(μ1−μ0) = ½(μ1+μ0)ᵀΣ⁻¹(μ1−μ0) − log(π1/π0)

左端只由 方向 决定，右端的常数项决定这个平面平移多少。三点推论：

(1) 法向量是 Σ⁻¹Δ，与先验无关；(2) 先验只改变平移量，不改变朝向；(3) 先验相等时边界恰是两类中心的垂直平分面（在 Σ⁻¹ 度量下）。

第 (3) 点用白化坐标看好：令 u = Σ⁻¹ᐟ²x，则两类的协方差都变成 I，边界变成 u 空间里的垂直平分面。几何上，等协方差的含义就是「两类是同一个球的两次平移」，而球的垂直平分面自然是平面。

反过来，若 Σ0≠Σ1，白化后两类的形状不同，垂直平分面不存在，最优点变成二次曲面（论文 lr_score 的 qcoef = 0.5(1−1/v) 就是那个二次项的系数）。

2.4 Fisher 判别：另一条路，同一个终点

Fisher 的思路与贝叶斯完全不同：他不假设分布，只要求「投影后两类分得开」。定义类间散度与类内散度之比：

J(w) = (wᵀΔ)² / (wᵀΣw)

分子是投影后的均值差平方，分母是投影后的（共享）方差。J 对 w 的缩放不变（分子分母同时乘 c²），所以只关心方向。

解法一（柯西—施瓦茨，最简洁）：令 u = Σ1/2w，z = Σ1/2Δ，则

J = (uᵀz)² / (uᵀu) ≤ ‖z‖² = ΔᵀΣ⁻¹Δ

等号当且仅当 u ∝ z，即 w ∝ Σ⁻¹Δ。最大值 ΔᵀΣ⁻¹Δ = d′²。

解法二（求导验证）：对 J 求梯度并令其为零，得 Δ = [(wᵀΔ)/(wᵀΣw)]·Σw，即 Σw ∝ Δ，同解。

结论：Fisher 的最优方向与贝叶斯后验的系数方向完全一致。这不是巧合——两者都在最大化同一个量 d′²，只是一个从分布出发、一个从散度出发。这也解释了为什么「LDA」这个名字下其实藏着两套叙事（生成式 / 判别式），而它们在两类问题上殊途同归。

顺带得到一个有用的量：最大化后的 J = d′²，正是 §2.2 中「均值差」与「方差」共同等于的那个 d′²。这也让 §2.2 的推导与 Fisher 视角对上了。

2.5 参数估计：三个估计量，一个隐藏的偏差

实践中 μ、Σ 未知，用样本估计（论文 §3.3）：

μ̂k = (1/nk) Σi:yi=k xi

Σ̂ = [(n0−1)S0 + (n1−1)S1] / (n−2)，　Sk = 类内样本协方差

为什么分母是 n−2 而不是 n？因为估了两个均值，每个均值吃掉一个自由度；两类合计损失 2 个自由度。这样 Σ̂ 才是 Σ 的无偏估计（(n−2)Σ̂ ~ Wishartd(n−2, Σ)）。

但这里有一个初学者常忽略的陷阱：Σ̂ 无偏，不代表 Σ̂⁻¹ 无偏。由逆 Wishart 的性质，

E[Σ̂⁻¹] = [(n−2)/(n−2−d−1)]·Σ⁻¹　（当 n−2 > d+1）

即 Σ̂⁻¹ 系统性放大了 Σ⁻¹，放大倍数随 d 增大。这就是「LDA 在 d 与 n 同阶时失稳」的代数根源，也解释了为什么需要收缩估计 Σδ（论文附录 C.4）。本实验在 d=50、n=300 时 d/(n−2)≈0.17，放大因子约 1.2，尚在可控范围——这是 RQ1 在 d 轴上「看不见差异」的原因之一（§5.3）。

2.6 判别方向的三个性质

(P1) 尺度不变。Σ⁻¹Δ 对特征的单位变换是协变的：若 x 变成 Ax，则 Σ 变成 AΣAᵀ、Δ 变成 AΔ，方向变成 A⁻ᵀΣ⁻¹Δ，恰是原方向在 A 下的像。这意味着标准化不改变 LDA 的分界面（只改变系数的数值）。这也是课件里那句「系数依赖单位」的技术内容。

(P2) 白化后是欧氏垂直平分面。见 §2.3。

(P3) 共线时方向爆炸。若 Σ 有接近零的特征值（特征高度相关），Σ⁻¹ 在该方向的方差被放大 1/ε，Δ 若在该方向有微小分量，方向就会被放大成主导。这是 LDA 在共线数据上「系数符号乱跳」的原因，也是论文 RQ4 关注「系数稳定 ≠ 预测稳定」的动机。

2.7 概率输出与它的含义

LDA 天然输出概率：p̂(x) = σ(β̂0+xᵀβ̂)，其中 σ 是 sigmoid。注意这里的概率是模型内在的，不是事后校准的。

它的可靠性完全取决于 A1、A2 是否成立。若假设成立，它就是参数模型下的极大似然估计（近似），概率应近似校准；若违背，它会输出过度自信的概率——因为 Σ̂⁻¹ 的放大效应会把 logit 推离 0，让概率贴住 0 和 1。

论文在乳腺锚点上量到了这一点：LDA 的 Brier 是 0.131，Logistic 是 0.020，6.5 倍；logloss 0.658 对 0.078。而同一组数据的 ΔAUC 只有 −0.0042。这个反差就是「AUC 盲区」的直接证据：排序对了，概率错了，而 AUC 只看排序（§4.3）。

3　Logistic 回归：只要一个线性 logit

3.1 一条假设，比 LDA 少得多

Logistic 回归对数据的假设只有一条：

(B1)　log[p(1|x)/p(0|x)] = β0 + xᵀβ　——logit 是线性的

它没有说 x 服从正态，没有说两类协方差相同，也没有说边界来自密度比。它只是把「对数几率是线性的」当作一个建模选择，然后用极大似然去拟合。

这一条与 LDA 的结论形式完全相同（§2.2 末尾）。差别在于：对 LDA 而言，线性 logit 是推导出来的结论；对 Logistic 而言，线性 logit 是出发点。所以 LDA 的假设集严格包含 Logistic 的——这正是「LDA 好用 ⇒ Logistic 也好用」的第一层理由（§4.1）。

3.2 似然与得分方程

给定 pi = σ(β0+xiᵀβ)，对数似然为

ℓ(β0,β) = Σi [ yi log pi + (1−yi) log(1−pi) ]

利用 σ′(z)=σ(z)(1−σ(z)) 求梯度。先算单个样本：

∂ℓi/∂zi = yi(1−pi) − (1−yi)pi = yi − pi

再对参数求导（∂zi/∂β = xi）：

∇ℓ = Σi (yi − pi)·[1, xi]　⇒　Xᵀ(y − p) = 0

这就是得分方程，也是代码 irls 收敛判据的来源（自检 t3 量到梯度范数 1.49e−13）。它有两条值得记住的解读：

解读一（矩匹配）：方程说「残差与每个特征正交」。所以 Logistic 的解是让模型的一阶矩与数据的一阶矩对齐。注意：它只匹配一阶矩，不匹配二阶矩。而 LDA 通过 Σ̂ 明确使用了二阶矩。这个差别正是 §4.4 效率差异的来源。

解读二（权重）：每个样本的贡献被 pi(1−pi) 加权——越靠近边界的样本权重越大，越确认的样本权重越小。这意味着 Logistic 的解由边界附近的样本主导，远离边界的样本几乎不起作用。

3.3 凸性：为什么一定有唯一解

对梯度再求导，Hessian 为

H = −XᵀWX，　W = diag(pi(1−pi)) ≻ 0

因为 W 正定，XᵀWX 半正定，所以 H 半负定 ⇒ ℓ 是凹函数。凹函数的最大值集合是凸集；若 X 满秩且无完全分离，则是严格凹，最优解唯一。

这条性质解释了一个实践差异：Logistic 的优化是「稳」的（凹、无局部极值、牛顿法二次收敛），而 LDA 的估计是「闭式但脆」的（一次矩阵求逆，条件数差就全盘皆输）。这也是为什么在高维或共线场景，人们宁可跑 Logistic 而不愿求 Σ̂⁻¹。

3.4 IRLS：把牛顿法写成加权最小二乘

牛顿步为 β ← β − H⁻¹∇ℓ，代入上面的梯度与 Hessian：

β(t+1) = β(t) + (XᵀWX)⁻¹Xᵀ(y − p)

把它改写成「对工作响应做加权最小二乘」的形式，就是 IRLS。定义

zi = zi(t) + (yi − pi)/[pi(1−pi)]

则每步求解 minβ Σi wi(zi − xiᵀβ)²。这就是「重加权」三个字的字面意思：权重 w 随当前参数更新，每轮解一个加权最小二乘。

初始化的经典选择是 pi=½（此时 W=¼I，第一步退化为普通最小二乘）、zi=yi。本实验的自检 t4 用 n=4000 验证了收敛解：cos(βLDA, βlogit) = 1.000——在大样本下两条完全不同的算法给出了同一个方向。这是 §4.2 命题的实验前身。

3.5 L2 惩罚：两种解释，一个公式

加惩罚的目标函数是

minβ −ℓ(β) + (α/2)‖β‖²

得分方程变成 Xᵀ(y−p) = αβ，Hessian 变成 −(XᵀWX + αI)，严格负定，所以即使数据完全分离也一定有唯一解。

同一个 α 有两种读法：

读法一（贝叶斯）：等价于给 β 加上 N(0, α⁻¹I) 的先验，做 MAP 估计。α 大 = 先验强 = 收缩狠。

读法二（数值）：等价于对 XᵀWX 加一个「山脊」，把条件数压下来。当特征共线或 d>n 时，没有这一项矩阵不可逆。

本实验用的是路径式的 α = {100, 10, 1, 0.1, 0.01}，从强到弱、热启动，每个点独立做内层 5 折选优（论文表 4）。这样做的目的是让「Logistic 的表现」不被一个任意选的 α 决定——否则 RQ1–RQ5 的比较会退化成「谁的调参运气好」。

一个常被忽略的细节：惩罚通常不加在截距上。因为截距承载的是类先验（§2.2 的第一项 log(π1/π0)），把它收缩向 0 等于强行假设两类等比例，会系统性地偏移决策面。

3.6 完全分离：Logistic 的「病」

如果存在某个方向能把两类完全分开（存在 β 使所有 yi(xiᵀβ)>0），则把 β 放大任意倍都能进一步降低损失，似然上确界在无穷远，MLE 不存在。表现为：迭代不收敛、系数发散、概率贴住 0/1。

LDA 在这件事上「看起来更稳」，但那只是因为它没有优化过程——它直接求逆，得到的是一个有限（虽然可能很不可靠）的数。所以「LDA 更稳定」在完全分离场景是一个假象：两者都在给不可信的概率，只是一个发散、一个沉默地错（论文 §3.6-2 记录了这一条协议偏差与处理）。

规范的解法是加 L2（§3.5）或改用 Firth 惩罚。本实验选了前者，并在协议里预先声明。

3.7 概率语义：两个模型说的不是同一件事

两个模型都输出 σ(β0+xᵀβ)，但含义不同：

LDA 的概率是「生成式反演」——先假设 x 怎么来，再用贝叶斯公式反推 P(y|x)。如果生成假设错了，反演就跟着错，而且错得系统性（§2.7 的过度自信）。

Logistic 的概率是「判别式拟合」——直接拟合 P(y|x) 的条件均值结构，不关心中间过程。它对分布形状的错误更宽容（因为没有用形状假设），但它只匹配一阶矩，因此在小样本、需要借用二阶结构时效率更低（§4.4）。

一句话总结这一节：LDA 用更多假设换更少方差，Logistic 用更少假设换更多偏差容忍。当假设成立时，前者赢在效率；当假设破时，后者赢在稳健。而本实验的核心发现是——在排序这个指标上，这个交换几乎不产生差异（§4）。

4　为什么 LDA 好用的场合 Logistic 也会好用

这一节是全解的核心，也是论文 §4.1–§4.2 与 §5.1 的全部数学底稿。论点可以压成一句：

等协方差高斯成立时，两个模型是同一个模型；AUC 只看方向，而两个模型的方向在同一个点收敛。

下面把它拆成三层命题，每层单独可证，合起来给出「几乎不能分开」的必然性。

表 3：三层命题的分工
层命题它排除了什么
第一层　同族A1–A2 ⇒ LDA 的后验就是 logistic 形式「两者是不同的模型族」这一误解
第二层　同极限两估计量都 → β*，且差为 Op(n−1/2)「两者的差异随 n 增大而累积」
第三层　同排序AUC 只是方向的函数，ΔAUC 由方向差决定「截距/校准差异会污染 AUC 比较」

4.1 第一层：同一个模型族

命题 4.1　若 A1（类条件高斯）与 A2（共享 Σ）成立，则

P(y=1|x) = σ(β0+xᵀβ)，　β = Σ⁻¹Δ，　β0 = log(π1/π0) − ½(μ1+μ0)ᵀΣ⁻¹Δ

证明　即 §2.2 的逐步代数，全部内容都在那里，此处不重复。

这个命题的含义：Logistic 的模型类 {σ(β0+xᵀβ) : β0∈ℝ, β∈ℝd} 包含 LDA 在 A1–A2 下产生的那个具体成员。LDA 是 Logistic 的一个参数子模型——不是「近似」，不是「类似」，是子集关系。

反向不成立：Logistic 的后验线性不蕴含 x 服从等协方差高斯。所以严格地说，Logistic 的假设集更宽。这个不对称是后面所有讨论的起点：LDA 的假设破了，Logistic 未必破；Logistic 的假设破了，LDA 一定也破（因为它假设更多）。

注意这里的逻辑方向容易被讲反。常见说法是「LDA 假设强所以更脆弱」——对，但它的推论不是「所以 LDA 更差」，而是「所以 LDA 失效的场景是 Logistic 的失效场景的子集」。若一个场景里 LDA 仍然好用，说明它的强假设大致成立，那么弱的那个必然也成立。

4.2 第二层：同一个极限

命题 4.2　在 A1–A3 下，且 n0,n1→∞、d 固定，则

β̂LDA →p β*，　β̂logit →p β*，　且 β̂LDA − β̂logit = Op(n−1/2)

证明（两半）

(i) LDA 一侧：μ̂k→μk、Σ̂→Σ 依概率（大数律），而 β̂=Σ̂⁻¹(μ̂1−μ̂0) 是这些量的连续函数（Σ 正定时求逆连续），故由连续映射定理 β̂LDA→Σ⁻¹Δ=β*。

(ii) Logistic 一侧：由命题 4.1，模型是正确设定的。总体得分方程为

E[y−σ(β0+xᵀβ)]·[1,x] = 0

在真值处，E[y|x]=σ(β0*+xᵀβ*)，故被积函数恒为 0，方程成立；又因 ℓ 严格凹（§3.3），解唯一。于是样本得分方程的解依概率收敛到总体解，即 β̂logit→β*。

(iii) 差为 Op(n−1/2)：两个估计量各自都是 √n 相合的（√n(β̂−β*) 渐近正态），故其差也是 Op(n−1/2)。两者之差不随 n 累积，而是随 n 缩小。

这一半的意义值得单独强调：常见的直觉「样本变大，两个模型的差异会更明显」是反的。差异随 √n 缩小。样本越大，二者越像。自检 t4 就是这个命题的极端情形：n=4000 时 cos=1.000。

还有一个细节让命题更可信：两侧的偏差方向并不相同。LDA 的偏差主要来自 Σ̂⁻¹ 的反演放缩（§2.5，量级 O(d/n)）；Logistic 的偏差来自只用一阶矩（丢掉二阶结构）。两个偏差都随 n 消失，所以极限相同，但小样本下的偏差方向可能相反——这解释了为什么 ΔAUC 的符号会随 n 随机翻转（§4.5 的胜率证据）。

4.3 第三层：AUC 只看方向

这是三层里最锋利的一层，因为它把「差异」压缩到了一个维度上。

命题 4.3（单调不变性）　设 s(x) 为打分函数，g 为严格递增函数，则 AUC(g∘s) = AUC(s)。

证明　AUC 的成对定义是 AUC = P(s(x1) > s(x0) | y1=1, y0=0)。由于 g 严格递增，事件 {s1>s0} 与 {g(s1)>g(s0)} 完全相同（连续打分下无并列），故概率相等。

推论 4.3.1（截距不得入内）　线性打分 s(x)=β0+xᵀβ 中，β0 对每个样本都加同一个常数，是严格递增变换，故截距不影响 AUC。

这条推论解决了一个长期困扰：为什么 LDA 与 Logistic 的先验/校准差别那么大，AUC 却几乎一样？因为先验只进截距（§2.3），而截距被 AUC 完全无视。

推论 4.3.2（ΔAUC 完全由方向差决定）　两个线性模型的打分之差只可能来自 (a) 方向不同、(b) 截距不同。由 4.3.1，(b) 不产生任何 AUC 差异。所以

ΔAUC = 0　当且仅当　β̂LDA 与 β̂logit 指向同一方向

这是整个实验的解释框架。它告诉我们：ΔAUC 不是「模型好坏」的度量，而是「两个估计方向差多少」的度量。于是「36 个点里 27 个 ΔAUC 落在 ±0.005 内」这句话，翻译过来就是「27 个点上两个方向几乎重合」——而由命题 4.2，这本就该发生。

4.4 残余差异：为什么不是零，而是千分位

既然极限相同、排序只看方向，为什么 ΔAUC 不是精确的 0？因为有限样本下两个方向的估计误差不同。三个具体来源：

(1) 参数计数不同。LDA 估 d + d(d+1)/2 + 1 个参数（均值、Σ 的上三角、先验）；Logistic 只估 d+1 个。在 A1–A2 成立时，前者是有效估计（达到 Cramér–Rao 界），后者只用了一阶矩，因此方差更大。这是经典的效率损失，量级是常数因子，不随 n 变。

(2) 加权方式不同。Logistic 的每个样本被 p(1−p) 加权（§3.2），边界附近的样本主导解；LDA 对所有样本等权（只用均值与协方差）。若边界附近恰有少量异常点，Logistic 的方向会被它们拉动，而 LDA 相对不敏感。

(3) 逆矩阵的病态。LDA 走 Σ̂⁻¹，当 d/n 不小或 Σ 近奇异时，方向被放大且不稳定（§2.5–§2.6）。Logistic 走凸优化，没有求逆这一步，因此在病态场景反而更稳（这也是为什么我们的 λ 轴与 γ 轴最终都由 Logistic 拿分，§5）。

三者叠加的结果是：两个方向相差 Op(n−1/2)，符号由噪声决定。这就是「千分位」的来源——在 n=300、d=5 的干净场景，两个方向的夹角标准差量到 0.060（LDA）与 0.062（logit）弧度，而对应的 ΔAUC 只有 ±0.001 量级。

一个有用的白化类比：在 u=Σ1/2x 空间里，LDA 的最优方向就是 u 空间中的均值差方向（因为 Σ 变成 I）。Logistic 拟合的是同一件事，只是它不知道「u 空间里球的半径是 1」，得从数据里学。学到的东西差不多，所以方向差不多。「差不多」的定量含义就是 Op(n−1/2)。

4.5 三条实证证据

证据一：36 个比较点的判定分布。27 个未分、6 个系统性平局、2 个 Logistic 胜、1 个 LDA 胜。如果两者真有系统性的能力差，判定分布应该严重偏斜；实际是压倒性地「分不出」（论文 §4.1）。

证据二：方向的一致性随 n 收敛。干净场景 n=300、d=5 时，两个方向的夹角标准差是 0.060 与 0.062；自检 t4 在 n=4000 时 cos=1.000。而乳腺锚点（假设明显破）的 cos 只有 0.50——方向分裂只发生在假设破的地方，且即便分裂，AUC 也只差 −0.0042，因为分裂发生在低方差方向上。

证据三：n 轴的胜率是一条带噪声的平线。n∈{40,60,100,200,500,1000,2000} 时，LDA 胜率在 0.477（n=2000）至 0.563（n=1000、d=2 变体）之间摆动，没有任何单调趋势；R=200 时胜率的标准误约 3.5 个百分点，这个带完全落在噪声内。拟合出的交叉点 n*≈2641 落在观测网格之外，按协议标为「外推」，不构成结论。

这三条证据合起来，构成了对「几乎不能分开」的三角验证：判定层分不出、方向层随时间收敛、噪声层解释得通。

4.6 三个推论

推论一（证据的可迁移性）。任何「LDA 在这个问题上表现好」的证据，同时也是「Logistic 会表现好」的证据——因为前者成立意味着 A1–A2 大致成立，而由命题 4.1–4.2，后者必然也好。反过来不成立：Logistic 好不蕴含 LDA 好。这就是为什么教科书里「小样本用 LDA」的建议在本实验的坐标系下没有获得支持（论文 §4.2）。

推论二（选型应看二阶维度）。既然排序层不可分，模型选择的信息只能来自概率、阈值与代价这几层。论文给出的证据是：乳腺锚点上 Brier 相差 6.5 倍（0.131 对 0.020）、logloss 0.658 对 0.078；在 w=5 的代价下，误分类代价相差约 9 倍。这些差异不在 AUC 里，报告 AUC 就永远看不见它们。

推论三（「无差异」是可证伪的命题）。由推论 4.3.2，ΔAUC≈0 等价于方向几乎重合，这是一个强陈述，不是「我们没测出来」。它可能被推翻：只要找到一个场景使两个方向系统性分裂，ΔAUC 就会显著。本实验确实找到了三个这样的场景（γ 轴、λ 轴的代价层、乳腺锚点的概率层），它们全部落在「假设被违背」的区域（§5）。

一句话收束：LDA 与 Logistic 的关系不是「两个竞争对手」，而是「同一个几何对象的两种参数化」。在等协方差高斯的区域内，它们只是在用不同的误差去逼近同一个方向；一旦离开这个区域，它们才真的开始讲不同的故事。

5　什么时候才分得开：五个分岔机制

§4 说「假设成立时不可分」。本节反过来问：假设破到什么程度，二者才开始讲不同的故事？实验给出的答案是五个机制，每个机制都对应一个可核对的数字。

5.1 机制一：协方差分歧（λ 轴）——两方一起死，第三方捡漏

λ 只放大正类的一半维度（§1.2）。λ>0 时贝叶斯最优判别式变成二次的，两个线性模型共用一个失效原因，所以它们的相对排名几乎不动：

λ=0：ΔAUC=0.0000，p=1.000，胜率 0.482（未判定）　　λ=0.8：ΔAUC=−0.0004，p=0.41，胜率 0.453（未判定）

λ 从 0 扫到 1，ΔAUC 始终没有越过 0.005 的门槛，胜率拟合出的交叉点 λ*≈0.50 被判为噪声。但绝对水平在塌：AUC 上界随 λ 单调下降。而 Quadratic Discriminant Analysis（QDA，允许 Σ0≠Σ1）在同一网格上把 AUC 拉回 0.892，Brier 从约 0.20 降到 0.132。

这一格的教训：模型比较必须区分「相对」与「绝对」。当天花板本身在下降时，两个模型谁高谁低已经不重要——重要的是「错在模型族，不在选手」（论文 §4.3 的标题即此）。这也解释了为什么「是否存在一方更抗错」这个 RQ2 的原问法，在本坐标系下得到的是否定答案：没有一方更抗错，因为两者错的方式相同。

5.2 机制二：分布形状（γ 轴）——唯一真正的交叉区域

γ 是保序的双射，不改变贝叶斯上界（论文附录 C.3）：它只改变估计的难度，不改变可分性。正因为上界不动，任何差异都只能来自估计，于是天平开始倾斜：

表 4：γ 轴的单调倾斜（n=300，d=5，λ=0）
γΔAUC（LDA−Logit）p（Holm）LDA 胜率判定
1.0+0.00030.400.530未判定
1.3−0.00070.0170.420系统性平局
1.6−0.00272.8e−70.335系统性平局

四个量同时单调：ΔAUC 从 +0.0003 掉到 −0.0086，p 从 0.40 掉到 0，胜率从 0.530 掉到 0.215。这是全实验唯一一处「方向性一致且随参数单调」的证据，也是唯一被判为「有胜负」的合成网格点。胜率 logit 拟合出的交叉点在 γ*≈1.08。

为什么是 Logistic 赢？两个原因叠在一起。其一，LDA 用样本均值与样本协方差，而幂变换 γ>1 把分布拉出长尾，高阶矩被尾部少数点支配，矩估计的效率暴跌；Logistic 不估矩，直接用似然，对尾部不敏感。其二，LDA 的 Σ̂⁻¹ 在重尾下更病态（§2.5 的放大因子被异常值进一步推高），方向更容易被拉偏。

值得强调量级：γ=2 时 ΔAUC 只有 0.0086，仍然是「百分位」而不是「十分位」。即使假设被明显违背，排序能力的差距依然很小——这恰恰再次印证 §4.3：AUC 对分布形状极不敏感。

5.3 机制三：估计崩塌（d 接近 n）——本实验没有进入的区域

理论上 LDA 真正会崩的地方是 d 与 n 同阶：Σ̂ 的秩最多 min(n−2, d)，当 d ≥ n 时不可逆，LDA 直接失效；当 d/n 接近 0.3 时，§2.5 的放大因子已经到 1.4 以上，方向明显不稳。

必须诚实说明的是：本实验的 d 轴没有进入这个区域。d 从 2 扫到 50，固定 n=300，d/(n−2) ≤ 0.17，放大因子约 1.2。结果也正是「无差异」：d 轴上 ΔAUC 的绝对值全部不超过 0.0012（d=50 时为 −0.0012），Holm 校正后的 p 全部不低于 0.08；胜率从 d=2 的 0.517 单调降到 d=50 的 0.440，方向上略偏 Logistic，但没有任何一点越过判定门槛。

因此论文 §4.2 的表述是「教科书『小样本选 LDA』在本坐标系未获支持」，而不是「该教科书结论错误」。二者差别很大：前者是关于我们这 36 个点的陈述，后者是关于所有数据的断言。若要检验后者，d 轴必须推到 d/n ≳ 0.3，这是本工作明确的局限（论文 §5.3）。

5.4 机制四：代价层——阈值把千分位放大成数量级

这是全实验最有实践价值的一格。设定漏报权重 w=5（漏一个正类比误一个负类贵 5 倍），比较两种阈值策略：固定 τ=0.5，与在内层交叉验证上选出的 τ*。

表 5：τ=0.5 与 τ* 的代价比（w=5）
锚点LDA 的 τ*代价放大约数主要成因
乳腺（BCW）0.05（贴下界）≈9×概率过度自信，τ* 被推到边界
心脏（StatLog）0.055≈2×同上，程度较轻
Pima（keep0）未贴界≈1.2×校准尚可

为什么 τ* 会贴在 0.05 的下界？因为 LDA 在这个锚点上的概率过度自信（§2.7）：正类样本的概率被推到接近 1，负类接近 0，于是「把阈值压低以多召回」的收益极大，最优点一路走到搜索区间的边缘。这本身就是一个信号：当最优阈值贴住搜索边界时，通常说明概率尺度错了，而不是阈值真的该在那里。

这一格回答了「千分位 AUC 差异有什么意义」这个质疑：在排序层差异是千分位，在代价层差异是数量级。因为代价函数对概率的绝对值敏感，而 AUC 完全无视绝对值（推论 4.3.1）。同一个模型，AUC 差 0.004，代价差 9 倍——两句话都对，只是回答不同的问题。

5.5 机制五：概率层——AUC 的盲区

乳腺锚点是五个机制里最锋利的一个：

ΔAUC = −0.0042（判为系统性平局）　但 Brier：0.131（LDA）vs 0.020（Logit）＝ 6.5 倍

logloss：0.658 vs 0.078　　cos(βLDA, βlogit) = 0.50

三个数字放在一起读：方向分裂了一半（cos=0.50），排序却几乎没差（ΔAUC=−0.0042），概率差了 6.5 倍。这不是矛盾，而是几何的必然：两个方向在高方差方向上的分歧对排序影响大，在低方差方向上的分歧对排序影响小；而概率的绝对值对所有方向的缩放都敏感。LDA 走 Σ̂⁻¹，把低方差方向的噪声放大成了 logit 的巨大偏移，于是排序没怎么变、概率全错了。

这也解释了为什么论文反复强调「报告应当报概率」：AUC 是一个对单调变换免疫的指标，它天生看不见校准失败。一个模型可以 AUC=0.85 却给出完全无用的概率，而任何只报 AUC 的评估都发现不了。

7　十条常见误解

Q1　AUC 只差千分位，这篇论文还有意义吗？
有意义，而且千分位正是结论本身。预注册要检验的命题是「两者是否可分」，千分位是支持这个命题的证据，不是它的反例。真正的价值在下一层：同样的数据，概率差 6.5 倍、代价差 9 倍。

Q2　胜率 0.215 与「判定 Logistic 胜」是一回事吗？
不是。判定需要 pHolm<0.05 且 |ΔAUC|>0.005 双条件；胜率只是符号一致性。γ=1.6 就是反例：胜率 0.335、p=2.8e−7（极显著），但 |ΔAUC|=0.0027 < 0.005，判为系统性平局。显著性说的是「方向稳」，幅度说的是「差得多」。

Q3　为什么 λ 轴没出现「Logistic 更抗协方差违背」？
因为两者错的方式相同：λ>0 使最优边界变成二次，而两个模型的边界都是线性的。它们对付不了同一个东西，所以相对排名不动。能抗的是 QDA，不是 Logistic。

Q4　既然 AUC 差不多，直接选简单的那个行不行？
不行，理由见 Q1。而且「简单」在这里也不成立：Logistic 要跑 IRLS 加 α 路径加内层 5 折，LDA 只需一次求逆。真正该问的是「我要的是排序、概率还是代价」：排序层随便选，概率层选 Logistic，代价层必须先看校准。

Q5　LDA 的系数能当特征重要性用吗？
不能。系数依赖单位、标准化方式、参照类（one-hot）与共变量（§2.6 的 P1）。换一个编码，系数全变，而 AUC 不变。要谈重要性，应报告标准化后的方向或直接做置换重要性。

Q6　cos=0.50 但 AUC 只差 0.0042，说明什么？
说明方向分歧集中在对排序影响小的方向上。这是 AUC 盲区的第二种表现（第一种是截距，§4.3.1）。它同时提醒：不要用「AUC 一致」去推断「模型一致」。

Q7　乳腺锚点为什么判「系统性平局」而不是「Logistic 胜」？
因为 ΔAUC=−0.0042，没越过 0.005。虽然胜率是 0.000（10 次重复 LDA 一次没赢）且 p=0.024，但幅度条件不满足。这条判定如实反映了规则：稳定的小差异不改判。

Q8　最优阈值贴在下界 0.05，是 bug 吗？
不是 bug，是信号。它说明概率尺度偏了（过度自信），最优点被推到搜索区间边缘。规范做法是先校准（Platt / isotonic），再选阈值；或者直接把 τ 的搜索区间放宽并检查是否仍贴界。

Q9　这套结论能外推到真实临床吗？
不能。三个锚点都是教学数据、单一 80/20 划分、n 有限，且正类定义是人为指定的。论文 §5.3 已明确声明。可外推的只有方法论：把假设拆成旋钮、先冻结协议、分层报告四个量。

Q10　如果重做一次，最该改什么？
两件事：把 d 轴推到 d/n≳0.3（§5.3 的空缺），以及在 γ 轴上加密到 1.0–1.4 之间（交叉点 γ*≈1.08 目前只有两个点夹着，精度不足）。其余部分的表现已经足够支撑现有结论。
