课程研究报告（PBL：LDA vs Logistic Regression）· 预注册—复现—证伪流程

线性判别分析与 Logistic 回归

协议冻结日期：2026-11-03（预注册见 §3.2） · 实验完成：2026-11-03 · 环境：Python 3.12 / NumPy 1.26.2 / 纯 numpy+stdlib 实现（无 scikit-learn）

摘要　线性判别分析（LDA）与 Logistic 回归是统计学习中最经典的一对「近亲」分类器：两者的判别边界同属线性族，教科书长期争论孰优孰劣。本报告以预注册流程（先冻结假设与判据，后跑实验）在 32 个合成控制点（200 次重复分层 CV，精确控制 n、d、协方差分歧 λ、偏态 γ 四个轴）与 3 个真实数据锚点（StatLog 心脏病 270×13、乳腺癌 569×30、糖尿病 Pima 768×8 双缺失协议）上系统比较二者，回答三个问题：两者何时几乎不可分？何时一方显著占优？差异沿哪一层级传导？主要发现：(i) 在「好条件」区域（高斯、等协方差、中等维度、n≥100）两者 AUC 差的绝对值均 ≤0.006，36 点中 27 点统计上无法判定胜负——「选哪个都无所谓」在排序能力这一维度上基本成立，且是被预注册预言过的；(ii) 交叉区域并非以 n 或 d 为轴，而是以假设违背的形态为轴：协方差分歧（λ 轴）使两者的相对天花板同步坍塌（λ=1 时二者 AUC 0.727 vs 贝叶斯上界 0.892，而 QDA 回到 0.877）——这是共同模型族错，不是一方错；边际偏态（γ 轴）才产生真正的胜负手：γ≥1.3 起 Logistic 系统性领先（幅度小但 200 重复下稳定），γ=2 越过预注册判胜门槛（Δ=−0.0086，p<0.001）；锚点同向——乳腺癌上 Logistic 拿下 10/10 重复；(iii) AUC 的千分位差异掩盖了概率与代价层的数量级差异：同一批实验里 Brier 在乳腺癌上相差 6.5 倍（LDA 0.131 vs Logistic 0.020），固定阈值 τ=0.5 的 w=5 代价在乳腺/心脏分别是 Logistic 的约 9 倍与 2 倍（Pima 两协议约 1.2 倍——任务本身难，谁都没校准好），LDA 最优阈值在乳腺被钉死网格下界 0.05、心脏贴界 0.055——两者共享边界「形状」，却不共享边界「位置」与概率刻度。结论以五槽位条件句给出（§5.4），并附完整协议偏差记录（§3.6）以保证复现诚信。

关键词　线性判别分析；Logistic 回归；贝叶斯上界；校准；阈值代价；预注册；Wilcoxon 符号秩；Holm 校正

1　引言

驱动问题来自课件的 PBL 场景：用给定数据训练一个分类器，输出患病概率，并以 5×漏诊 + 1×误诊 的非对称代价做选择——LDA 与 Logistic 回归，该选谁？ 课件幻灯片（第 10 页）指出「模型比较要回答的问题不同」，但没有给出可检验的答案。本研究把它改写为五个研究问题：

RQ1　两者在什么条件区域里排序能力（AUC）统计上不可分？
RQ2　协方差结构违背（λ 轴）时，损失由谁承担？是否存在一方更抗错？
RQ3　边际分布偏态（γ 轴）时，是否存在「Logistic 占优」的交叉区域？交叉点在哪？
RQ4　样本量 n 与维度 d 是否是胜负轴？（教科书主张「小样本选 LDA」）
RQ5　即便 AUC 接近，概率输出、阈值、代价与系数方向上的差异有多大、由什么机制驱动？

直觉图景是「梯子」：假设 → 参数 → 概率 → 边界 → 代价，模型选择的代价沿链条逐级放大——排序层（AUC 只依赖分数单调性）在顶端几乎不动，代价层（阈值 + 非对称损失）在底端差异巨大。本报告用数据逐级验证。

本文贡献　(1) 受控坐标系：构造 λ（类间协方差分歧）与 γ（边际偏态）两个可精确调节的假设违背轴，把「何时选谁」从口号变成可测量的交叉线；(2) 五级评价阶梯：把模型比较拆成 假设 → 参数 → 概率 → 边界 → 代价 五层逐层报告，显式区分「排序不可分」与「概率/代价不可混用」；(3) 预注册与偏差审计：先冻结判胜规则与代价函数再跑实验，并把过程中出现的全部偏差（含两处真实 bug）如实列入 §3.6；(4) 三个真实锚点用于检验外推，其中 Pima 采用 keep0 / drop0 双协议暴露 0 值缺失哨兵的影响。

组织　§2 固定记号与形式化定义；§3 描述数据、冻结协议、模型、生成器、度量与统计程序；§4 报告四个轴上的结果并给出交叉区域地图；§5 按五级阶梯讨论并给出五槽位条件结论；附录 A–F 依次给出超参数、相关工作、补充推导、统计程序、36 点全表与复现信息。

2　预备知识

本节固定全文的记号、受控生成过程与两个模型的等价形式，并给出后文反复引用的四个量：贝叶斯上界、代价最优阈值、胜率与交叉点。全部定义与 §3.4 的实现、附录 A 表 4 的冻结常量一一对应。

2.1　记号

样本 x ∈ ℝd，标签 y ∈ {0,1}，类先验 πk = P(Y = k)，取 π₁ = 0.44（与三个锚点 0.35–0.44 的正类比例同量级）。n 记训练集规模，d 记特征维数；β 记线性系数、β₀ 记截距；λ 为类间协方差分歧强度，γ 为边际幂变换指数，τ 为判决阈值，w 为漏报（FN）相对误报（FP）的代价权重。Φ 记标准正态分布函数，σ 记 sigmoid。

2.2　形式化定义

定义 2.1（受控生成过程 G(n, d, λ, γ)）　设 x ∈ ℝd。基础分布为类条件高斯

x | y = k ~ N(μk, Σk)，　μ0 = 0，　μ1 = SEP · e1，　SEP = 1.46575

Σ0 = Id，Σ1 = diag(1+3λ, …, 1+3λ, 1, …, 1)，其中前 ⌈d/2⌉ 个对角元被放大，λ ∈ {0, .1, .2, .4, .6, .8, 1} 度量类间协方差分歧强度。观测特征由逐坐标的符号保持幂变换给出

Xj = sign(xj) · |xj|γ，　γ ∈ {1, 1.3, 1.6, 2}

γ = 1 时退化为恒等映射（近高斯基准）。完整的 n × d 网格、先验与重复次数见 §3.4 与附录 A 表 4。

定义 2.2（共享协方差 LDA 与线性后验）　在 Σ0 = Σ1 = Σ 的假设下，判别函数与后验 logit 分别为

δk(x) = xᵀΣ̂−1μ̂k − ½ μ̂kᵀΣ̂−1μ̂k + log π̂k

log [P(Y=1|x) / P(Y=0|x)] = β₀ + xᵀβ，　β = Σ̂−1(μ̂₁ − μ̂₀)，　β₀ = −½(μ̂₁ + μ̂₀)ᵀΣ̂−1(μ̂₁ − μ̂₀) + log(π̂₁ / π̂₀)

参数由类内矩估计得到，Σ̂ 近奇异时以伪逆兜底。收缩变体 LDA-LW 使用 Σ̂δ = δ · Swithin + (1 − δ) · (tr S / d) · I，δ 由内层 OOF 选择（动机见附录 C.4）。线性性是共享协方差假设的直接后果：x 的二次项 xᵀΣ̂−1x 在两类密度比中相消（推导见附录 C.1）。

定义 2.3（L2 正则 Logistic 回归）　P(Y=1|x) = σ(β₀ + xᵀβ)，σ(z) = 1/(1+e−z)。参数由带 L2 惩罚的负对数似然最小化得到，惩罚强度 α = 1/C；求解为 IRLS 加步长减半（阻尼预算 1 → 0.0078），α ∈ {100, 10, 1, 0.1, 0.01} 的路径按降序 warm-start，并由内层 5 折 OOF 负对数似然选择。收敛失败计入 fail ledger。

定义 2.4（贝叶斯上界）　对任意决策规则，其 AUC 不超过真后验概率所能达到的 AUC，记为贝叶斯上界 AUC*。在等协方差高斯下，令

d′ = √( (μ₁ − μ₀)ᵀ Σ−1 (μ₁ − μ₀) )，　AUC* = Φ(d′ / √2)

该解析式用于把「模型差」与「模型族天花板」区分开：当两者同时低于上界，损失属于模型族而非选手（推导见附录 C.2）。

定义 2.5（阈值代价与代价最优阈值）　给定漏报权重 w ≥ 1，

C(w, τ) = w · FN(τ) + FP(τ)，　τ*(w) = argminτ ∈ [0.05, 0.95] C(w, τ)

其中 FN(τ) 与 FP(τ) 为阈值 τ 下的漏报、误报计数。oracle 版本使用真后验概率，经验版本使用内层 OOF 概率（τ* 与 α 只允许在内层产生）。w ∈ {1, 5, 20}，主场景为 w = 5（与课件 PBL 的 5× 漏诊 + 1× 误诊一致）。τ* 的机制性质见附录 C.5。

定义 2.6（胜率、交叉点与判定三分）　对合成点 p 的第 r 次重复（r = 1, …, R）记配对差 dr = AUCLDA − AUClogit，胜负指示 signr = 1{dr > 0}，则胜率 π̂(p) = R−1 Σr signr。沿轴变量 x 的交叉点由 logit 回归

logit [ P(LDA 胜) ] = a + b · x，　x* = −a / b

给出，即 π̂ = 0.5 处；若 x* 落在观测轴域之外则标注为「外推」。判定采用三分规则：pHolm < 0.05 且 |ΔAUC| > 0.005 ⇒ 判定；显著但 |ΔAUC| ≤ 0.005 ⇒ 系统性平局；其余 ⇒ 未分。该规则先于任何结果冻结。

2.3　结构性联系与读数框架

注 2.1（共享边界族）　LDA 的贝叶斯正确后验本身就是线性 logit（定义 2.2），因此二者并非「线性 vs 非线性」，而是同一线性边界族里「用哪一条线」：LDA 用 μ̂ 与 Σ̂−1 直接拼出方向 (μ̂₁ − μ̂₀) / n，Logistic 用似然梯度从数据中学出方向。二者的差别因而落在系数的估计方差、概率的校准刻度与边界的位置上，而不是边界的函数形式上。

注 2.2（五级评价阶梯）　把比较拆成 假设 → 参数 → 概率 → 边界 → 代价 五层。排序度量（AUC）仅依赖分数的单调性，因此对后三层的差异天然不敏感——这是全文的读数框架：排序层几乎不动，代价层差异最大。第五层的差异由 w · FN 放大，故「AUC 千分位」与「代价倍数」可以同时为真。

3.3　模型与算法

LDA（共享协方差）：设 X|Y=k ~ N(μₖ, Σ)，则后验 logit 为线性： log [P(Y=1|x)/P(Y=0|x)] = β₀ + xᵀβ，　β = Σ⁻¹(μ₁−μ₀)，　β₀ = −½(μ₁+μ₀)ᵀΣ⁻¹(μ₁−μ₀) + log(π₁/π₀) 实现为矩估计 + 伪逆兜底；另设 James–Stein 型收缩变体 LDA-LW：Σ̂_δ = δ·S_within + (1−δ)·tr(S/d)·I（δ 由内层 OOF 选择，δ_LW 报告）。

Logistic：P(Y=1|x) = σ(β₀+xᵀβ)，IRLS + 步长减半（阻尼预算 1→0.0078），L2 路径 α=1/C 由内层 5 折 OOF 负对数似然选择。收敛失败逐次计数记入 fail ledger。

关键联系（课件第 7 页的严格化）：LDA 的贝叶斯正确后验本身就是线性 logit——因此两者不是「线性 vs 非线性」，而是同一个线性边界族里用哪条线：LDA 用 (μ₁−μ₀)/n 与 Σ⁻¹ 的信息直接拼出方向，Logistic 用似然梯度从数据里学出方向。文献 [1] §4.3 的 4× 方差差距即由此而来。

3.4　合成生成器（受控坐标系）

μ₀=0，μ₁ = SEP·e₁；Σ₀=I，Σ₁ 的前 ⌈d/2⌉ 个对角元 1→1+3λ（λ=协方差分歧强度）；特征边际经符号保持幂变换 |x|^γ·sign(x)（γ=偏态强度，可逆 ⇒ 不改变贝叶斯 AUC 的理论值，但改变样本经验分布的形状与估计噪声）。贝叶斯上界 AUC 对 (d,λ,γ) 单调映射由 10⁵ 次蒙特卡洛估计（用真值的二次判别分数），缓存复用。γ=1,λ=0 时理论 AUC=0.8503（MC 0.8503±0.0004），为全网格校准点。

3.5　度量与统计

AUC（排序）、Brier 与 logloss（概率刻度）、代价 C(w,τ)=w·FN+FP 在固定 τ=0.5 与内层 OOF 选出的 τ* 两处报告、bootstrap 95% CI（2000）、系数方向余弦 cos(β̂_LDA, β̂_logit) 与自助角度 SD（仅稳定性网格点）。配对 per-rep 差 → Wilcoxon 符号秩（正态近似、结点校正、n≥6）→ Holm 按 stage×metric 家族降阶段。胜率 logit 拟合给出交叉点 −a/b；若 −a/b 超出观测轴范围则标注为外推。

3.6　协议偏差与修正记录（复现诚信声明）

下列偏差全部发生于「跑出结果之前」或「结果核验阶段」，逐条如实记录：

  1. 泄漏哨兵设计缺陷：t6 原断言「训练均值应偏离全局均值 >0.05」，在分层子抽样下噪声地板仅 ~0.01，该哨兵永真/永假失衡。修正为「scaler 参数必须与训练行均值逐位一致（<1e-12）」。此修正发生在全量运行前，不影响任何结果数值。
  2. 锚点尺度错配 bug：quick 运行中 e6 的 bcw/pima 上 Logistic 恰好 0.5000（常数退化指纹）。取证发现 run_anchor 的 Logistic 分支在外层标准化空间训练、却拿原始尺度特征预测。修复（scaler.transform 对齐）后重跑——quick 的 d50 大差值（−0.038）与 n40 的「LDA 70% 胜率」均为该 bug 与 20 次重复噪声的复合伪影，全量运行后消失。教训保留：小重复数下的方向性效应必须先过「全量复跑」闸门。
  3. 摘要脚本自毁字段：分析脚本 report_data.json 因 delete 顺序丢失锚点明细，改由缓存文件直接重建（本报告锚点数字全部来自缓存重取，与 regime 摘要交叉核对一致）。
  4. 锚点 OOF 简化：锚点评估以池化 OOF 同时做 τ* 选择与报告（未分内外层二次拆分），已在 §5.3 局限声明。

4.2　RQ1/RQ4（n 与 d 轴）：教科书「小样本选 LDA」在本坐标系未获支持

阴性结果（如实报告）　d=5 的 n 扫描（40→2000，γ=λ=0 干净高斯）胜率全程徘徊在 0.477–0.555，无任何一段显著偏向 LDA；胜率 logit 拟合的交叉点 n≈2641 在观测范围之外（外推，不予采信）。d 轴同样平淡：n=300 固定、d=2→50，胜率从 0.517 缓降至 0.440，soft 交叉 d≈22，但全段 |ΔAUC|≤0.0012。quick 运行里「n40 LDA 七成胜率」被证伪为 IRLS 未收敛伪影（§3.6-2）。

唯一的小样本 LDA 优势出现在 n=40 × 协方差收缩因子网格（e5_n40，Δ=+0.0059，p_Holm=0.0003）：逐因子看，纯 LDA（f=1）在小 n 反输 Logistic（−0.0069），f=0.25（重收缩）才反超（+0.0063，CI 不含 0，见 F6 附表）——救小样本的不是 LDA，是 Σ 收缩；LDA-LW 变体在心脏上把 AUC 从 0.9046 提到 0.9111（超过 Logistic 的 0.9104）而同方向成立。H1 的修正结论：小样本效应存在，但轴挂错了——它挂在正则化强度上，不挂在「LDA vs Logistic」标签上。

4.3　RQ2（λ 轴）：天花板共同坍塌，错在模型族不在选手

随协方差分歧 λ 从 0 升到 1，LDA 与 Logistic 的 AUC 几乎逐点重合地下滑：0.841/0.841（λ=0）→ 0.747/0.747（λ=0.8）→ 0.727/0.727（λ=1）；同期贝叶斯上界却上升（0.850→0.892），因为真边界变成二次型后判别信息更多。相对天花板差距同步扩大：−0.009 → −0.13 → −0.164。λ=1 探针点加入 QDA：0.877，几乎回到上界（0.892），Brier 从两者的 ~0.20 掉回 0.132。结论：λ 轴上的损失是线性族共同的天花板，不存在「谁更抗协方差违背」——配对检验 32 点全段不显著正对应此机制。胜率 logit 拟合的 λ≈0.50 交叉实质是平局区噪声，判为无。

4.4　RQ3（γ 轴）：真正的交叉区域在偏态

符号保持幂变换 γ∈{1,1.3,1.6,2}（n=300, d=5, λ=0）：γ=1 平局（0.8433/0.8431）；γ=1.3 起 Logistic 系统性领先（Δ=−0.0007，p_Holm=0.017——千分位但 200 重复下稳定）；γ=1.6 Δ=−0.0027（p=2.8e-7）；γ=2 Δ=−0.0086（p≈0，胜率 0.215），且两者同低于上界 −0.029/−0.020。胜率交叉 γ≈1.08：几乎只要边际偏离高斯，天平就向判别式偏。机制：γ 变换使类条件密度在 μ₁ 方向左偏厚尾，Σ̂ 的尺度信息被尾部污染，矩估计的 β̂ 首先失真；似然路径 + L2 收缩对此更鲁棒。锚点同构复现：乳腺癌上 Logistic 胜率 10/10（Δ=−0.0042，p=0.024），心脏 Δ=−0.0058（p=0.032）——真实数据的「类高斯违背」方向与 γ 轴一致。

4.6　综合：交叉区域地图

5　讨论与结论

5.1　梯子的每一级

把 §4 装进五阶段框架：假设层决定谁会失真（LDA 失真于偏态与刻度，Logistic 失真于共线方向）；参数层 LDA 用 Σ⁻¹ 直拼、Logistic 用梯度下降学，前者快而脆、后者稳而偏；概率层是 AUC 盲区所在——排序对单调变换不变，所以 LDA 的过度自信在 AUC 上完全隐身，Brier/logloss 才显形；边界层两者同族同形状（图 5），交叉区域因此几乎不改变 ROC 而主要改变线的摆位；代价层摆位差被 w·FN 放大成数量级（图 3）。用户直觉「AUC 千分位 ⇒ 无所谓」在 27/36 点成立——但成立的范围恰恰是预注册要找的「平局区」，出了平局区，差异按上述路径逐级放大。

5.2　与文献的对话

Eklund et al. 2012「几乎相同」≈ 我们的平局区全貌；2016 年「Logistic 多数微优」≈ γ/共线轴与锚点方向；文献 [1] §4.3 预告的 LDA 方向方差劣势可复核，但只在「小 n × 协方差压力」叠加处显形（n40×收缩因子网格自助角度 SD：LDA 0.189 vs Logistic 0.164；干净 n300·d5 网格两者几乎相同：0.060/0.062），且其代价在 AUC 上不可见。三点张力均可由「轴是违背形态（γ、共线），不是 n/d 本身」调和。

5.3　局限

  1. 合成族限制：违背只沿幂变换与对角协方差两轴，未测混合类条件形状/非线性边界区（QDA/NB 探针仅一点）。
  2. 锚点 OOF 简化（§3.6-4）使 τ* 略偏乐观，两模型同受影响，方向性结论不变但绝对值慎引。
  3. 教学数据非临床队列：心脏 270 条、Pima 哨兵缺失均为课程语境样本，结论不迁移到临床决策。
  4. 锚点 10 重复的 Wilcoxon 功效有限：pima_drop0（p=0.065）处于灰区，未强判。
  5. 贝叶斯 MC 上界有 ±0.0005 级估计噪声，已避开用它做小差值判定。

5.4　结论（五槽位条件句）

在（样本量）n≥100 且（变量类型）以连续特征为主、（假设压力）边际近高斯、协方差近共享、（错误代价）对称或已做过阈值重校准、（用途）只需要排序/评分的区域——选谁都行，选顺手的；这是预注册命中 27/36 点的平局区，「无所谓」是精确结论不是敷衍。

在边际偏态（γ≥1.3）、类间协方差差异伴随共线、需要校准概率、固定默认阈值 0.5、或非对称代价直接落地（w≥5 且无再校准预算）——选 Logistic（γ=2 合成点与心脏/乳腺锚点一致支持，p_Holm<0.05）。

在n≤50、特征≈高斯、可承受 Σ 收缩调参成本、且需求是小样本快速基线/生成式解释——选 LDA-LW（带收缩的 LDA）而非裸 LDA（e5_n40 的 +0.0059 属收缩变体，裸 LDA 同点反输；心脏上 LDA-LW AUC 0.9111 亦反超 Logistic）。

在任何需要解读系数/方向的场景：先报方向余弦再选模型——乳腺锚点（cos=0.50）证明 AUC 平局完全可以掩盖「两个近正交的判别方向」。

附录 B　相关工作

LDA 与 Logistic 的关系在判别式与生成式两类建模的框架下讨论：LDA 由类条件高斯 + 共享协方差直接给出后验（Bishop 2006 [9] §1.6；Hastie et al. 2009 [1] §4.3），Logistic 对后验做指数族参数化并以极大似然拟合（Hilbe 2011 [10]）。[1] §4.3 给出了著名的渐近结论：当生成假设成立且 n 充分大，LDA 以约 Var(Σ⁻¹(μ₁−μ₀))/n 与 logistic 相差 4× 的方差劣势收敛到同一方向；当假设违背（边界非线性）logistic 更灵活。Eklund, Nordin & Adelin (2012) [2] 在模拟与真实数据上发现两者「几乎相同」，而 同组后续的多元扩展与大规模复现系列（41 项已发表预测研究）[3] 则报告 Logistic 在多数数据集上略优、数据越噪差距越大——两组结论的张力正是 RQ1–RQ3 的动机。真实数据锚点均为公开经典集：StatLog 心脏数据（Vehicle/UCI 仓库，Quinlan et al. 1994 [4]，原始来自 Cleveland 队列，本报告使用的教学拷贝已剔除坏表头版本，见 §3.1）；乳腺癌细胞学（Wolberg & Mangasarian 1990 [5]，经 scikit-learn 分发）；Pima 糖尿病（Smith et al. 1988 [6]，UCI 镜像，0 值缺失哨兵按双协议处理）。校准度量采用 Brier（1950 [7]）与 Niculescu-Mizil & Caruana（2005 [8]）的阈值后校准框架。

与上述文献不同，本研究的贡献不在「再比一次」，而在把比较放到受控的合成坐标系里找交叉线（λ、γ 可精确调），并用真实锚点检验外推；同时把「代价层」纳入预注册判据，这是教学语境里通常缺失的一环。

附录 C　补充理论推导

C.1　LDA 后验 logit 的线性性

设 X | Y = k ~ N(μk, Σ)，先验 πk，两类协方差相同。对数后验比为

log [P(1|x) / P(0|x)] = log(π₁/π₀) − ½ log|Σ| − ½(x − μ₁)ᵀΣ−1(x − μ₁) + ½ log|Σ| + ½(x − μ₀)ᵀΣ−1(x − μ₀)

展开后 xᵀΣ−1x 项在两式中系数相同而相消，余下

= log(π₁/π₀) + xᵀΣ−1(μ₁ − μ₀) − ½(μ₁ᵀΣ−1μ₁ − μ₀ᵀΣ−1μ₀)

即 β = Σ−1(μ₁ − μ₀)，β₀ = −½(μ₁ + μ₀)ᵀΣ−1(μ₁ − μ₀) + log(π₁/π₀)。可见二次项必须相消，边界才是线性的——共享协方差假设是线性性的充要来源，这与注 2.1 一致。

C.2　等协方差高斯下的贝叶斯上界 AUC = Φ(d′/√2)

取判别分数 s(x) = β₀ + xᵀβ，β = Σ−1(μ₁ − μ₀)。则 s 在两类下的均值差为

E[s|1] − E[s|0] = (μ₁ − μ₀)ᵀΣ−1(μ₁ − μ₀) = d′²

而两类方差同为 Var[s|k] = βᵀΣβ = (μ₁ − μ₀)ᵀΣ−1ΣΣ−1(μ₁ − μ₀) = d′²。两正态同方差时 AUC 只依赖标准化均值差

AUC* = Φ( (E[s|1] − E[s|0]) / √(2 · Var[s]) ) = Φ( d′² / √(2 d′²) ) = Φ(d′ / √2)

γ = 1、λ = 0 时 d′ = SEP，网格的理论校准点据此给出（§3.4 的 10⁵ 次蒙特卡洛估计与之一致）。

C.3　幂变换不改变贝叶斯上界

g(x) = sign(x)·|x|γ（γ > 0）是 ℝ → ℝ 的严格单调双射，逐坐标作用后仍是 ℝd → ℝd 的双射。由于任何决策规则的 AUC 只依赖样本在该双射下的像与原标签的排序一致性，双射不改变最优可达 AUC。因此 γ 只改变有限样本下的估计难度（分布形状、尾部厚度、协方差的条件数随之上升），不改变贝叶斯天花板——这正是把 γ 解释为「纯违背轴」、并据此判断「落后的一方是估计问题还是模型族问题」的依据。

C.4　收缩估计 Σδ 的动机

当 d 与类内样本量同阶、或 Σ 近奇异（λ > 0 时 Σ₁ 的条件数随 λ 增大）时，Σ̂−1 会把噪声方向放大，伪逆兜底只能避免数值崩溃、不能避免方差膨胀。James–Stein 型收缩

Σ̂δ = δ · Swithin + (1 − δ) · (tr S / d) · I

把样本协方差谱向常数谱拉平：δ → 1 退化为样本协方差，δ → 0 退化为球形度量。δ 由内层 OOF 选择，因此收缩强度本身不消耗外层测试信息。这解释了小 n 网格点上 LDA-LW 相对裸 LDA 的收益方向。

C.5　代价最优阈值随 w 单调下降

把 FN、FP 视为阈值的连续函数，C(w, τ) = w·FN(τ) + FP(τ) 对 τ 求导并令其为零，得最优性条件

dC/dτ = −w · n₁ · f₁(τ) + n₀ · f₀(τ) = 0　⟺　f₁(τ) / f₀(τ) = n₀ / (w · n₁)

即最优阈值由类条件后验密度比与代价比共同决定：w 越大，右侧越小，阈值 τ* 越低（更倾向报正类）；且它落在后验概率刻度上，与 AUC 无关。这为「AUC 接近而 τ=0.5 代价可差数倍」提供了机制解释：排序相同而概率刻度不同，同一固定阈值下的混淆矩阵就不同。

附录 D　统计程序与说明

D.1　Wilcoxon 符号秩检验的正态近似

对配对差 d₁, …, dn（舍弃 d = 0 的观测）取秩 ri，统计量 W+ = Σdi > 0 ri。在零假设下

E[W+] = n(n+1)/4，　Var[W+] = n(n+1)(2n+1)/24 − Σt(t³ − t)/48

其中第二项为结点（tie）校正，t 为各结点组的观测个数。检验统计量取连续性校正后的 z = (W+ − E[W+] − ½ sign(W+ − E[W+])) / √Var。本报告要求 n ≥ 6 才使用该近似（合成点 n = 200 次重复，锚点 n = 10 次重复，均满足）。

D.2　Holm 逐步下降校正

把同一家族（stage × metric）内的 m 个 p 值升序排列 p(1) ≤ … ≤ p(m)，自 i = 1 起依次与阈值 α/(m − i + 1) 比较；一旦出现 p(i) > α/(m − i + 1) 即停止，该检验与其余假设均不拒绝。与 Bonferroni 相比它严格更强（拒绝集是后者超集）且同样控制 FWER。家族定义见 §3.5；报告中的 pHolm 即按此程序给出。

D.3　胜率 logit 与交叉点

以轴变量 x 对胜负指示 signr 做二项 logit 回归（等价于对胜率做加权 logit 拟合）

logit π̂(x) = a + b x，　x* = −a / b

x* 为预测胜率等于 0.5 的轴坐标，即交叉点。报告同时给出 b 的符号（决定谁在轴的高端占优）与 x* 是否落在观测轴域内：若 x* 超出观测范围，则该交叉点属外推，不参与判定。

D.4　配对 bootstrap 区间

对每个比较点，对配对差向量 {dr} 做 2000 次有放回重抽样，取 2.5% 与 97.5% 分位数作为 95% 区间。bootstrap 给出差值的幅度区间，Wilcoxon 给出符号一致性，二者互补：判定同时要求幅度越过 0.005 且符号系统性。
