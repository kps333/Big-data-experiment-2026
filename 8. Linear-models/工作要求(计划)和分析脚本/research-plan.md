# 研究计划：LDA 与 Logistic 回归的适用边界——一个条件化模型选择研究

> 状态：v1（2026-11-03）。本计划按一般学术论文流程组织：研究问题 → 文献定位 → 假设 → 数据与方法 → 实验矩阵 → 分析计划 → 图表 → 阶段分工 → 终稿规范 → 质量门。
> 最终交付物：**单文件、离线可读、论文格式的 HTML 报告**（`report/linear-models-crossover.html`）。

---

## 1. 定位与研究问题

**一句话定位**：在"高斯 + 共享协方差"的理论交叉点上，用可控的合成数据与三个真实锚点数据集，系统地找出 LDA 与 logistic regression **谁在什么条件下更可信**，产出一条五槽位条件句式的模型选择规则。

- **RQ1（效率轴）**：当生成假设成立（共享 Σ 高斯）时，LDA 相对 logistic 的小样本效率优势有多大？它随样本量 n 如何衰减？交叉点 n* 在哪？
  - 依据锚：Efron (1975) 报告 logistic 在正态假设下效率约 85–95%，但 n 小时的差距在实践中常被放大/掩盖——需要在 50≤n≤2000 的网格上复核。
- **RQ2（负担轴）**：固定 n，维度 d 上升时，LDA 的 Σ 估计负担 d(d+1)/2 与 logistic 的"无分布假设"负担如何改变天平？交叉点的 n/d 比值约为多少？
- **RQ3（压力轴）**：逐步破坏 LDA 假设（协方差分歧 λ、偏态 γ），logistic 的稳健性优势从哪个压力水平开始压倒效率损失？——即两个方向的"交叉"是否对称。
- **RQ4（可信度轴）**：在 AUC 打平的区间里，校准（Brier/logloss）、固定代价损失（5FN+1FP）、系数稳定性（bootstrap 重采样散布）三者是否给两者分出胜负？
- **RQ5（外推）**：以上合成交叉规律在 heart / BCW / Pima 三个真实锚点上是否可复现、以何种形式修正？

**总目标（不可变）**：不是选出一个赢家，而是**找到 LDA↔logistic 的交叉曲面**，并把它压缩成可教、可引用的条件选择规则。

## 3. 假设（H1–H6，先注册后实验；每条附证伪标准）

| # | 陈述 | 检验 | 证伪标准 | 强度评级 |
|---|------|------|----------|----------|
| H1 | 假设成立时 LDA 在 AUC 上不劣于 logistic，差距随 n 单调收缩，∃n*（约 200–800）后两者不可区分 | E1，配对 ΔAUC 的 bootstrap CI | 小 n 段 ΔAUC CI 不>0，或差距随 n 不收缩 | smoking-gun |
| H2 | 固定 n，d↑ 使 LDA 相对优势翻转；交叉点近似 n/d ≈ 10–20 | E2 | ΔAUC 对 d 无单调趋势，或交叉 n/d 在区间外且 CI 不含 | hoop |
| H3 | 协方差分歧 λ↑ 时 logistic 反超，且反超发生的 λ 远小于"理论可检测差异"所需水平 | E3a，λ 扫描 | 大 λ 下 LDA 仍不劣 | smoking-gun |
| H4 | 偏态 γ↑ 时同样 logistic 受益，但效应弱于 λ | E3b | γ 效应 ≥ λ 效应 | hoop |
| H5 | AUC 打平区间内，两模型在 Brier/校准斜率/系数稳定性上仍可分 | E1/E2 子集 + E4 | 四指标 CI 全部重叠 | doubly-decisive（若成立最能支持"差异影响可信度多于排名"） |
| H6 | 冻结代价 5FN+1FP 下的最优阈值 τ* 与模型选择结论耦合：改变代价，排序可能翻转 | E4 | τ* 在 {1:1, 5:1, 20:1} 三档下排序稳定 | hoop |

## 4. 数据

### 4.1 合成生成器 G(n, d, λ, γ, π)
- 类均值：μ₀ = 0，μ₁ = Δ·e₁，Δ 由目标贝叶斯 AUC≈0.85 反解（共享 Σ 情形用 Mahalanobis 距离公式；λ>0 时用数值蒙特卡洛估计贝叶斯 AUC 作为天花板参照）。
- 协方差：Σ₀ = I_d；Σ₁ = 对角阵，前 k=⌈d/2⌉ 个分量方差从 1 线性插值到 r(λ)（λ=0 ⇒ r=1 共享；λ=1 ⇒ r=4 强分歧）。类先验 π = 0.44（对齐 heart 阳性率）。
- 偏态：对特征施加保号幂变换 |x+εc|^γ·sign(x)，γ=1 为无偏态，γ∈{1, 1.3, 1.6, 2}；变换后重估贝叶斯 AUC。
- 每个网格点 **200 次独立重复**（每次独立抽数据+分层 80/20 划分+折内协议）。
- 对照性说明：贝叶斯 AUC 随 (λ,γ) 变化，因此报告**相对性能 = 模型 AUC − 贝叶斯 AUC**，防止"某格点大家都差"被误读。

### 4.2 真实锚点

## 5. 模型与统一评估协议

### 5.1 实现（纯 numpy，无 sklearn 依赖——本机执行只需 numpy≥1.20）
- **LDA**：折内类均值 + 池化 Σ̂；决策函数 δ_k(x) = xᵀΣ⁻¹μ_k − ½μ_kᵀΣ⁻¹μ_k + ln π̂_k；数值稳定用 Cholesky，退化时伪逆。变体：收缩正则 Σ̂_δ = (1−δ)Σ̂ + δ·(tr Σ̂/d)·I，δ∈{0, ¼ LW, ½ LW, 1}（Ledoit-Wolf 解析 δ̂）。
- **Logistic**：IRLS/Newton + L2 罚，C∈{0.01, 0.1, 1, 10, 100}，**C 与 λ-L2 选择全部在训练折内层 5 折 CV 完成**；迭代上限 50，步长减半防发散；完全可分时由 L2 兜底。
- **QDA-lite 参照**（仅 E3a 用）：λ=1 极端下 QDA 参数 2·d(d+1)/2 的可行性对照，说明"分歧不是 logistic 赢，是 QDA 的地盘"。
- 所有标准化/one-hot/先验/类均值/Σ̂/罚参数选择：**只在训练折内拟合**（继承工作单纪律，无泄漏）。
- 固定划分种子 2026；重复用 seed+rep。

### 5.2 指标四件套 + 天花板
1. ROC-AUC（主）；2. Brier、log-loss（校准）；3. 固定代价 5·FN+1·FP 在 τ=0.5 与 τ*（τ* 由内层验证折选取，预注册扫描 0.05:0.95 步长 0.01）；4. 系数/方向稳定性：LDA 的 Σ⁻¹(μ₁−μ₀) 方向与 logistic β 在 bootstrap 100 次下的散布（球面标准差、与全样本方向夹角 95% 区间）。
5. 每格点报告贝叶斯 AUC（合成）以便"相对性能"。

### 5.3 统计检验族
- 重复间配对：每 rep 同时得两模型指标 → Wilcoxon 符号秩（族=一个实验 E1–E5 一组，**Holm-Bonferroni** 校正）。
- 区间估计：rep 层面 cluster bootstrap 1000 次给 Δ 的 95% CI（对 200 rep 重采样）。
- 交叉点估计：对网格 (n 或 d 或 λ) 拟合 logistic 回归 P(LDA wins | 轴值)，报告 50% 胜负分界的轴值及 CI——这就是论文主结果"交叉点"。
- 真实锚点：重复分层 5 折×10（n 小，折间配对），报告同上四件套 + 折配对检验。

## 9. 终稿 HTML 报告规范（论文格式）

- 单文件：CSS 内联，无 CDN/字体外链；MathJax 不引——公式用 Unicode + `<sup>/<sub>`（如 `δ_k(x) = xᵀΣ⁻¹μ_k − ½μ_kᵀΣ⁻¹μ_k + ln π̂_k`），关键推导可用等宽排版块。
- 纸面感排版：衬线正文、栏宽 ~72ch、编号章节、图表 caption、`@media print` 优化（用户可打印成 PDF 当"论文"读）。
- 章节骨架：Title/Authors → Abstract（结构化：背景/方法/结果/结论四句）→ 1 引言（驱动问题 + 贡献三条）→ 2 背景与等价性推导（两条概率链：P(Y|X) 对数线性 ⟸ 高斯共享Σ；LDA 线性边界 ⟸ xᵀΣ⁻¹x 抵消）→ 3 相关工作（文献表 §2）→ 4 实验设计（假设注册、生成器、协议）→ 5 合成结果（E1–E5，F1–F4）→ 6 真实锚点（E6，F5，含 heart 数据勘误小节）→ 7 讨论：交叉曲面解读 + 五槽位条件规则（F6）→ 8 局限（教学数据非临床队列、模拟重复≠独立现实数据、单生成族外推有限）→ 9 结论 → 参考文献（编号制）→ 附录：全网格结果表、可复现性（种子、版本、运行命令）。
- 结论硬要求：模型选择表述必须写成**条件句**（当…(样本量/类型/假设压力/代价/用途)时，选…，因为…），禁止"X 优于 Y"裸结论。
