# 大数据实践课程作业仓库

存放《大数据实践》课程各讲次的作业、实验材料与 AI 协作记录。
仓库对应本地课程源目录：`D:\M\大数据实践`。

## 目录结构

仓库根目录下，每个课程一个文件夹，课程内统一为五类子目录：

```
<课程名>/
├── 数据/                       datasets、资产与中间数据（csv / json / png / zip）
├── PPT/                        课程课件（.pptx）
├── 工作要求(计划)和分析脚本/     工作计划、实验 notebook、分析/构建脚本、依赖声明与 readme.md
├── report/                     生成的最终报告（pdf / html / md 及图表）
└── AI对话记录/                  与 AI 协作的对话导出（Markdown）
```

### 各目录存放内容

| 目录 | 存放内容 |
| --- | --- |
| **数据** | 原始数据、处理后数据、数据包及其说明（如 `data/`、`assets/`、`data-ctg/`）。 |
| **PPT** | 课堂讲解与实验介绍课件。 |
| **工作要求(计划)和分析脚本** | 工作要求/实验设计（`WORKPLAN.md`、`plan.md`、`experiment-design.md` 等）、实验 notebook、分析与构建脚本（`scripts/`、`experiment/`）、`requirements.txt`，以及本目录的 `readme.md`（运行环境与依赖说明）。 |
| **report** | 最终生成的报告文件及支撑图表。 |
| **AI对话记录** | 从 DSH 会话导出的 Markdown 对话（含提问、助手思考与答复）。**第 6 讲该目录置空**（按课程要求），以 `.gitkeep` 占位。 |

## 课程列表

1. `6. multiple-test` —— 多重检验校正
2. `7. Naive-Bayes` —— 朴素贝叶斯
3. `8. Linear-models` —— 线性判别分析与 Logistic 回归

## 说明

- 教师参考、学生工作表模板、设计论证、证据包、评审稿等长篇参考性文件，以及虚拟环境、缓存、临时目录与历史归档，未纳入本仓库。
- 各课程「工作要求(计划)和分析脚本/readme.md」中的依赖列表由脚本 import 静态扫描生成，仅作参考；实际运行请以报错信息与 notebook 内说明为准。
- AI 对话记录中的「思考过程」为可折叠区块，GitHub 网页默认收起，点击即可展开。
